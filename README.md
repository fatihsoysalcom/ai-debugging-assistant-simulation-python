# AI Debugging Assistant Simulation Python

This Python script simulates an AI-powered debugging workflow. It processes user data, intentionally introducing errors, and then uses a rule-based 'AI assistant' to analyze the resulting exceptions and provide debugging suggestions. The example demonstrates how AI can quickly pinpoint potential issues and suggest fixes based on error messages and stack traces.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
